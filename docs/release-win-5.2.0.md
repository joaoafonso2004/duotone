Duotone para Windows 5.2.0 — a mesma versão do iPhone

No Windows a 5.2.0 é igual à 5.1.9: a correção desta versão (a pausa no ecrã bloqueado e nos AirPods) é só do iPhone. Sai para as duas apps terem o mesmo número.

Da 5.1.9 (para quem vem de antes): o Radio com dois lados ("Songs like this one" e "Mix", num menu que nasce da pastilha), o Mix de tudo o que ouves, e abrir a app já não te mete numa Jam antiga (o Speed volta a funcionar).
