Duotone for iPhone 6.0.3

Improved
- Skipping is smooth: the cover's move to the next song now runs in iOS itself, so changing song can't make it stutter.
- The cover no longer dims for a moment on every skip. It only pulses when a song takes a while to load.

Minimum version: 6.0.1
