Duotone para Windows 5.4.4

Melhorado:
- A reprodução evita atualizações repetidas de estado quando o leitor já está pronto.
- As letras reutilizam os controlos de cada verso: ao avançar a música, só as linhas que mudam precisam de ser atualizadas.

Esta versão acompanha também as correções do AutoMix e da Queue no iPhone.
