# O que verificar no Duotone 5.1.1 (iPhone e Windows)

A 5.1.0 não chegou a sair: no Windows o CI parou num teste que não aceitava os finais de linha do Windows (o teste, não a app), e no iPhone o GitHub respondeu com um erro ao publicar. A 5.1.1 é a mesma versão, com o teste corrigido. Passaram os 243 testes, também numa cópia com os finais de linha do Windows.

O que verificar é o mesmo: [VERIFICAR-5.1.0.md](VERIFICAR-5.1.0.md).

Releases: [iOS 5.1.1](https://github.com/joaoafonso2004/duotone/releases/tag/ios-v5.1.1) · [Windows 5.1.1](https://github.com/joaoafonso2004/duotone/releases/tag/win-v5.1.1).
