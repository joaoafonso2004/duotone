Duotone iOS 5.4.5 — atualizar os teus presets

Novo:
- No equalizador, escolhe um preset teu, ajusta as bandas e toca em Update “<nome>” para o substituir. O botão só aparece quando há alterações.
- O preset mantém o nome e a ligação aos teus aparelhos. Save as preset continua a guardar uma cópia.
