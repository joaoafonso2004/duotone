Duotone for Windows 7.1.0

New
- Command palette (Ctrl+F): opens over everything to search your songs, artists and playlists as you type, jump to recent searches, run quick actions or set a sleep timer. Choose "See all results" for server search.
- Download Liked Songs for offline listening, and see how many songs are saved on your PC, the disk space used and "Remove all downloads" in Settings › Windows.

Fixed
- Lyrics with per-word timing no longer show raw timing tags in the text.

Minimum version: 7.1.0
